Acerca de esta Pokédex

Una Pokédex en español. Todos los datos salen de PokeAPI, una API pública y gratuita mantenida por la comunidad, y las imágenes del repositorio de sprites de PokeAPI.

Qué puedes hacer

  • Buscar cualquier especie por nombre o número y filtrar por tipo y generación.
  • Ver su ficha: descripción del juego, estadísticas base, habilidades, tabla de daño recibido y cadena evolutiva.
  • Cambiar a la ilustración variocolor y escuchar su grito.
  • Moverte entre fichas con las flechas del teclado, y pulsar / en el listado para buscar.

Cómo funciona

Es una web estática publicada en GitHub Pages. Al publicarla se genera una lista con todas las especies, sus nombres en español y sus tipos, así que el listado carga de una vez. Cada ficha pide sus datos a PokeAPI desde tu navegador. El código está en GitHub.
